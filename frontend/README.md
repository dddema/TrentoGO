# frontend

## Project Setup

```sh
npm install
```

then copy `.env` to a new file named `.env.local` and insert your key for google api.

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
